# Test Application (Inspower Core)

A new foundation platform built from scratch: landing page, sign-in, optional two-factor
authentication with reminders, password rules, users with a fixed Super Admin role plus editable
roles and permissions, organization and settings, theme and appearance, backup and restore, audit
log, notifications, background jobs and health. Works on phones, tablets and desktops.

## Start here

1. Read the approved plan: [`docs/architecture/new-application-plan.md`](docs/architecture/new-application-plan.md).
2. To begin building, open a Claude Code session on this repository and paste the prompt in
   [`docs/architecture/START-HERE-prompt.md`](docs/architecture/START-HERE-prompt.md).

No application code exists yet. Phase 0 (Foundation) is the first step.
